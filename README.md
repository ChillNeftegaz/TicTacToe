# Крестики-нолики

Игра для двух игроков. Сделано на чистом HTML, CSS, JS.  
Без фреймворков — только логика, анимации и сохранение статистики.

## Фишки

- X и O (крестики и нолики)
- анимация клика и победной встряски
- сохранение счёта побед после закрытия браузера (localStorage)
- белая вспышка при сбросе статистики
- кнопка «Начать заново» и «Сбросить всё»

## Как играть

1. Первый игрок — X, второй — O
2. Кликай по клеткам — ход меняется автоматически
3. После победы или ничьей появляется кнопка «Начать заново»
4. Статистика побед остаётся даже после перезагрузки страницы

## Технологии

- HTML (сетка Grid)
- CSS (градиенты, тени, анимации)
- JS (массивы, события, localStorage)
